>
> It’s a command-line toolkit for managing coding-agent sessions across terminals
> and machines.
>
> Open a task in its own Git worktree and tmux slot. See what’s running. Resume a
> conversation, or move it to another machine and pick up there.
>
> The short clip shows the local worktree and session flow. It uses an idle agent
> stub so the commands are reproducible without an agent account; the README
> covers the real agent and remote workflows.
>
> `t` supports Claude Code and Codex session workflows, with Cursor tools too.
